The Roadmap

Phase 1 Train Your First AI Model

No typing code yet — just drag, drop and train. Use Machine Learning for Kids to build a model that reacts to your words, face, or numbers. Then wire it into a Scratch game. This is real machine learning, just with a friendly interface.

Phase 2 Go Visual with Teachable Machine

Open Google Teachable Machine in any browser. Train an AI to recognise your face, hand signs, or voice — in under 5 minutes. No account needed. Instant results you can share with friends or embed in a website.

Phase 3 Learn Python in the Cloud

When you're ready for real code, use Google Colab — a free cloud notebook that runs on any laptop or Chromebook. Zero setup. You write Python, Google's computers do the heavy lifting. Try your first AI project from an existing Kaggle notebook.

Phase 4 Build & Ship Your First Project

Use Replit to build and host a real app — a chatbot, image classifier, or something you invent. Replit's AI assistant explains every error in plain English. Push your code to GitHub so you have a portfolio from day one.

Safety & Setup

  • 🔒
    Use a Supervised Google Account Google Colab needs a Google account. Set up a shared or supervised account so a parent can check in on your projects any time.
  • 💳
    Set Spending Limits on Any Paid APIs If you ever use a paid tool (like OpenAI), set a hard cap — €5/month is plenty. Most of what you need is totally free to start.
  • 🤖
    Use AI as Your Tutor When you get stuck, ask ChatGPT or Claude: "Explain this Python error to me like I'm 12." You'll learn faster this way than watching tutorials.
🎓 Pro Tip — Your AI Tutor

Any time you're confused by code or an error message, just paste it into Claude or ChatGPT and try this prompt:

"Explain this Python error to me like I am 12 years old, and show me how to fix it step by step."

Start Your GitHub Portfolio Today Every project you build goes on GitHub. Even your first Colab notebook. In two years you'll have a real portfolio that speaks for itself.
